    How it works

    1. Choose a Marlin version. bugfix-2.1.x has the latest fixes.
    2. Search for your printer and select its configuration, or check Supply your own configs to build from your own files.
    3. Choose a build environment (the default suits most boards).
    4. Click Request build. GitHub opens a pre-filled request. Submit it.
    5. A few minutes later a download link is posted on that request, and GitHub emails you.

    You need a free GitHub account to submit a request.
